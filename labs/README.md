# 配套实验路线（全栈规划版）

**目标**：同一条教学主线同时覆盖机械、制造、电子、固件、控制、机器人软件与 AI，不强制任何初学者购买 CNC、机器人本体或昂贵计算设备。

详见：[全栈课程蓝图](../FULL_STACK_CURRICULUM.md)。

## 三档参与方式

| 档位 | 条件 | 适合的活动 |
| --- | --- | --- |
| L0 零硬件 | 普通电脑 | CAD、结构分析入门、仿真控制、感知算法、ROS 2 与模型推理案例 |
| L1 低成本实验 | 基础开发板与低压传感器，可选 3D 打印 | 传感器、编码器、固件、低能量执行机构 |
| L2 专业设备 | 受训人员管理的实验室、制造车间或企业 | CNC 车铣、材料/电机性能测试、整机集成与安全验收 |

## 单项实验选题池

- 机械：关节剖面、传动比选型、材料强度估计、尺寸公差堆栈
- 加工：CNC 车削/铣削工艺规划、零件可制造性评审、质量测量方案（机床实操仅限合格培训与场地）
- 力学：受力简化、有限元边界条件、网格收敛、振动与温度影响
- 电驱：电机参数测量、转矩-转速-效率曲线、发热/散热、FOC 原理仿真
- 嵌入式：PWM/ADC、编码器、CAN 通讯、实时任务、故障检测
- 控制：位置/速度闭环、模型参数变化和外部扰动对控制的影响
- 感知：图像、深度、触觉、传感融合、状态估计
- 机器人软件：驱动抽象、ROS 2 通信、日志、回归测试
- AI：任务级规划、模仿学习、VLA 模型适用条件、泛化评测
- 工业设计：CMF、维护通道、外观与散热/结构/装配的平衡

## 每项实验至少提供

1. 学习目标与先修知识
2. 所属档位、预算范围与设备要求
3. 工具/固件/软件/模型版本与可替代方案
4. 原理和关键公式（必要时提供推导）
5. 完整步骤、输出与失败情形
6. 测量指标、复现实验和验收标准
7. 可公开的原始数据与示意图来源
8. 安全等级、测试日期、贡献者与审阅者

## 安全要求

- 默认使用仿真或低风险设备开展实验。
- CNC 金属切削、旋转机械、高功率电机、电池、工业机器人等操作有飞屑、卷入、触电、火灾和碰撞风险，必须在合格设备、培训及现场安全制度下进行。
- 真实设备上电与运动控制应遵循制造商指导，设置硬件保护、急停、限位及隔离；未经验证的开源代码不得直接用于危险工况。
