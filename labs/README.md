# 配套实验（规划版）

目标：让学习者在没有真实机器人硬件的情况下，逐步尝试具身智能相关的软件与仿真实验。

## 实验格式
每个实验应包含：
1. 实验目标和先修知识
2. 系统要求（操作系统、CPU/GPU、内存）
3. 精确的软件与依赖版本
4. 安装和运行指令
5. 预期输出或截图
6. 常见错误及排查
7. 复现实验的日期与维护者
8. 许可证、数据或模型来源

## 安全原则
实验默认优先采用仿真。涉及真实硬件时，应增加限位、急停、隔离区、速度/力限制和异常恢复说明；未经独立验证的控制代码不可直接用于危险工况。
