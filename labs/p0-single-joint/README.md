## 第一步：从物理开始

假设一个绕固定轴旋转的关节，角度为 \(\theta\)（弧度），角速度为 \(\omega\)，绕轴的转动惯量为 \(J\)。我们先忽略重力、齿隙、摩擦死区、电机电气动态、齿轮弹性与采样延迟。其动力学为：

\[
J\dot{\omega}=\tau-b\omega+\tau_{ext},\qquad \dot{\theta}=\omega
\]

- \(J\)：转动惯量，单位 kg·m²；越大越难加速。
- \(\tau\)：控制器命令的扭矩，单位 N·m。
- \(b\)：粘性阻尼系数，单位 N·m·s/rad。
- \(\tau_{ext}\)：外部扰动扭矩。

为了让关节转到目标位置 \(\theta^*\)，使用最简单的 PD 控制：

\[
\tau_{cmd}=\operatorname{clip}\left[K_p(\theta^*-\theta)-K_d\omega,-\tau_{max},\tau_{max}\right]
\]

当角度误差很大时，控制器会试图施加更大扭矩；达到最大扭矩时会饱和。速度反馈可以抑制过度摆动。

## 第二步：运行代码

在仓库根目录打开终端：

```bash
python labs/p0-single-joint/simulate.py
```

程序会打印最终角度（rad）、最终误差（rad）、最大命令扭矩（N·m）、**绝对机械功积分（J）**。

在默认参数下，本项目作者对代码运行得到如下示例输出（浮点结果可能因环境略有变化）：

```text
final_angle_rad: 0.999984
final_error_rad: 0.000016
peak_command_torque_Nm: 0.800000
abs_mechanical_work_J: 0.060373
```

默认目标是 1.0 rad（约 57.3°）。这里的 **abs_mechanical_work_J = ∫|τω|dt** 只是关节命令扭矩与速度的绝对机械功积分，用于比较实验中的机械工作强度；**不代表电池耗电量、电机电能损耗或真实效率**。

## 第三步：改变参数、导出数据

例如，把位置控制增益从默认值改大：

```bash
python labs/p0-single-joint/simulate.py --kp 1.5 --kd 0.3 --csv joint_output.csv
```

或者给关节加一个短暂的外力矩扰动：

```bash
python labs/p0-single-joint/simulate.py --disturbance -0.2 --csv disturbed_output.csv
```

`--disturbance -0.2` 表示在 2.0 秒至 2.3 秒间施加 -0.2 N·m 的恒定外力矩。输出 CSV 列包含：时间、角度、角速度、命令扭矩、扰动扭矩。可以用 Excel 或 Python 绘图比较曲线。

还可以尝试：

```bash
python labs/p0-single-joint/simulate.py --kp 0 --kd 0
```

关掉反馈控制以后，这个原本静止、无外部扰动的关节将不会自己移动。

## 第四步：自检与验收

在仓库根目录运行：

```bash
python -m unittest discover -s labs/p0-single-joint -p 'test_*.py' -v
```

当前包含六项测试：扭矩限幅、达到目标位置、零反馈时静止、扰动影响、参数校验、CSV 导出。**测试通过只能说明代码在这些条件下符合预期，不代表真实系统已得到工程验证。**

## 五个练习题

1. 将 `--kp` 设为 0.2、0.8、2.0，分别导出数据。位置达到目标的快慢有何变化？
2. 保持 `--kp 1.5`，分别使用 `--kd 0.05` 与 `--kd 0.5`；观察是否产生超调。
3. 加入 -0.2 N·m 的短时扰动，控制器在扰动结束后能否恢复目标位置？
4. 阅读 `simulate.py`，解释为什么扭矩被限制在 ±0.8 N·m。
5. 现在假设转动惯量增加一倍，直觉上响应会怎样变化？在源代码的 `Config` 中修改参数验证推测。
