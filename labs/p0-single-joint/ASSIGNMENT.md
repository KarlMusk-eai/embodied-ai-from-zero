# P0 课程作业与参考评分标准

## 提交材料

- 两组不同 `kp`、`kd` 设置下的 CSV 输出（不要把大量 CSV 提交进主仓库，可放作业仓库）。
- 两张结果曲线或一个简单表格，比较最终误差、响应时间、是否超调和命令扭矩峰值。
- 200～500 字解释：为什么关节有转动惯量、为何扭矩要限幅、为何“机械功积分”不能表示真实耗电。
- 自己提出一个“这份模型缺少的物理因素”，解释如何在未来课程中加入。

## 评分标准（100 分）

| 项目 | 分值 |
| --- | ---: |
| 能独立运行代码和测试，记录环境 | 20 |
| 指标、单位和曲线整理清楚 | 25 |
| 正确理解 PD、惯量、扭矩限制 | 25 |
| 能解释简化假设和模型局限 | 20 |
| 可复现且注明所改参数 | 10 |

## 延伸题

自选一个负载关节的应用场景，列出真实电机选型还需增加的参数（例如效率、持续扭矩、峰值扭矩、热限制、减速比、编码器分辨率），**不需要购买或连接任何硬件**。
