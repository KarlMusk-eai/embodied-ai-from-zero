# Embodied AI From Zero
### 从零开始学习具身智能

**KarlMusk-eai 发起的免费、中文优先、面向全球贡献者的全栈具身智能开放课程。**  
*A free-to-read, community-driven learning project about embodied AI, robotics and real-world automation.*

> 🚧 **早期建设中（Early draft）**：本仓库已经公开，教学内容正在编写。部分课程和实验仅为规划，尚未经过完整测试。正式内容及代码许可仍在确认；公开可见不等于任意转载或商业使用已获授权。

## 我们想解决什么问题？

一台机器人从来不只是软件模型：从结构设计、金属加工、力学分析、电机驱动和嵌入式固件，到运动控制、环境感知、大模型与工业设计，都需要跨学科协作。初学者却常常面临知识分散、工程接口缺乏讲解、实验难复现的问题。本项目希望建立一套**从零部件到整机、从底层驱动到高层智能**的分级教学体系，并把真实产业约束带进课程。

**目标不是只教一个品牌的机器人，也不是把所有自动化产品都称为具身智能。** 我们欢迎传统自动化、工业视觉、机械臂、移动机器人、机器人学习及核心零部件等多条技术路线，在可验证证据下展示各自的适用边界。

## 课程的三种内容

1. **主线课程（`chapters/`）**：零基础通识与跨学科必需知识，逐步理解机器人完整系统。
2. **技术专题（`tracks/`）**：机械制造、力学仿真、电机电控、嵌入式、机器人控制、感知、AI、工业设计和工业自动化等领域各自深入，允许技术路线并存。
3. **企业和产品资料（`vendors/`）**：厂商可以提交技术专题；也可以保留自己的 GitHub 仓库，由本项目提供入口和使用说明。课程不出售排名，也不把厂商宣称视为独立验证结果。

## 一起编辑（欢迎新手）

- **纠错或提问**：使用 [Issues](../../issues)。
- **贡献教材、代码、插图或实验**：Fork 本仓库，修改后提交 [Pull Request](../../pulls)，经审核合并。
- **企业技术投稿**：阅读 [厂商专题指南](vendors/README.md) 并使用 [产品页模板](vendors/COMPANY_TEMPLATE.md)。请说明产品归类、技术证据及相关利益关系。
- **发现安全或版权问题**：请先提出不包含任何密钥或保密信息的说明，避免把敏感资料公开到 Issue。

文档由人审核、按版本记录修改。鼓励引用原始论文、官方技术文档和可复现的工程数据；未经测试的部分应明确标注。
