# 专题：工业自动化与具身智能的交汇

**定位**：为工业自动化企业、集成商、机器人开发者和初学者提供一条面向生产环境的技术路径。

## 为什么单独设专题？
在工厂里，“通用性”并不是唯一目标。可维护性、节拍、可靠性、换型成本与质量追溯，通常直接决定方案是否值得部署。

## 建议章节
1. 自动化单元基本组成：PLC、传感器、执行器、工控机、MES
2. 视觉检测与 AOI：光源、相机、标定、缺陷判定
3. 机械臂与末端执行器：抓取、夹具、节拍与碰撞
4. 机器人和设备的通讯：常见工业协议与接口边界
5. 柔性生产与换型：规则系统、示教、学习方法的比较
6. 异常处理：检测漏检、抓取失败、设备故障与人工接管
7. 项目经济性：ROI、部署成本、运维和产能约束

## 提交案例时说明
- 被解决的真实问题及场景约束
- 原有方案、替代方案、比较依据
- 可公开的数据与测试环境
- 成功情况、失败情况和适用边界

企业可提交自己的设备或方案专题，也可提供官方技术仓库链接。此专题同时接受传统自动化与具身智能技术内容，不将其人为对立。
