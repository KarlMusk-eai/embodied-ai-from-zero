# 第 0 章：认识具身智能

**难度**：零基础  
**前置要求**：无  
**本章目标**：理解机器人感知—决策—执行闭环，区分传统自动化与智能机器人的关系。

## 0.1 具身智能是什么？
具身智能不是简单地“给机器人装上大语言模型”。更实用的理解是：智能系统通过某种身体（实体机器人或其他执行载体）与环境交互，获取观测、选择行动，并依据行动反馈调整后续行为。

一个典型的机器人工作流程可以写成：

`传感器观测 → 状态估计 → 任务/动作决策 → 运动控制 → 作用于环境 → 新观测`

这只是抽象框架。真实系统可能是集中式、分层式，或者包含端到端学习模型；没有哪一种架构是唯一标准。

## 0.2 自动化与具身智能是什么关系？
固定规则的包装机、工业机械臂、移动机器人和视觉语言动作模型控制的机器人，可以使用相似的电机、相机和机械结构，但其适应环境变化的方式可能截然不同。

评价时不要只问“像不像人”，而要问：
1. 任务环境是否相对固定？
2. 工件或目标发生变化时，系统如何处理？
3. 感知结果如何参与动作决策？
4. 异常是否需要人工重编程？
5. 技术收益是否超过部署和维护成本？

## 0.3 一个工业案例
设想一条零件检测产线，需要识别不同类型的零件，并将缺陷件分类放置。

- **传统自动化路径**：固定输送机构 + 规则化视觉检测 + 专用分拣机构。
- **可重构机器人路径**：视觉定位 + 机器人抓取 + 根据任务切换分拣策略。
- **学习型系统路径**：在部分感知或操作环节引入数据驱动模型，提高对某些变化的适应能力。

三种路线都可能成立。**更复杂的智能技术不必然意味着更高的商业价值**；要结合节拍、误判率、稳定性和成本选择。

## 0.4 本章小练习
任选一款公开可查的工业机器人或自动化设备，写 300 字说明：
- 它有哪些传感器和执行器？
- 哪些过程是固定规则？哪些部分能适应变化？
- 一旦产线换型，哪些步骤需要人工介入？
- 你会如何验证它的宣传性能？
